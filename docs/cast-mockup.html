What this shows

  • Controller / output split. The phone drives the screen, it never mirrors it — the same mental model as the existing remote mode, so the UI stays familiar whether or not the desktop is connected.
  • Full-screen output only. One slide, centred, sized to fill the TV.
  • Blank is a first-class control — one tap to black out mid-service.
  • Song sections, Bible verses and announcements reuse the models already in model/ (Song, Bible, Announcement), so standalone mode is a new output target, not a new content layer.

Interactive: click a row, use ←/→ or space, press b to blank.
